Get the latest news directly from your terminal!

## Requirements

*HeaderNews* requires the libraries below in order to function

- [NewsAPI](https://newsapi.org/)
- [Rich](https://github.com/textualize/rich)


```
pip install newsapi-python rich
```

Besides that, you need to go to the [NewsAPI](https://newsapi.org/) website, generate an API key (for free), and paste it into the prompt that will show up when you initally use *HeaderNews*. After entering the API key, you can then use *HeaderNews* as you wish moving forward.

## Usage 

First, you need to install *HeaderNews* to get started: 

```
pip install HeaderNews
```

After successfully installing *HeaderNews*, you can use it as such: 

```
headernews
```

You will see a table of contents, showing you the latest news headers, sources, brief description, and a clickable link to the full article. However, due to some restrictions, *HeaderNews* can only show up to 50 news articles in a day. But that should be enough for your daily news needs...
